# Known Reference Behavior

This reconstruction was based on the known DentMemo Consent artifacts.

The product had a clean blue/white dental-software visual direction and a workflow equivalent to:

- Add Patient
- Select Treatment
- Patient Reads
- Patient Signs
- PDF Emailed
- Saved Securely

Known sample generated document properties:

- Header: DentMemo Consent
- Clinic name
- Procedure consent title
- Patient
- Doctor
- Tooth
- Consent body
- Signature & Acknowledgements
- Consent reference
- Signer
- Signed timestamp
- Electronic handwritten-signature statement
- "Generated using DentMemo Consent"

A known sample was a Dental Photography / Media Consent.

This file exists to keep Claude Code aligned with the prior product rather than turning the rebuild into a generic form builder.
