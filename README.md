# Thejus Editorial — WordPress Theme

A lightweight classic WordPress theme built from the supplied mobile website reference.

## Install
1. Zip the `thejus-editorial-theme` folder (a ready zip is included separately).
2. In a self-hosted WordPress dashboard go to **Appearance → Themes → Add New → Upload Theme**.
3. Upload the zip and activate it.
4. Set your site title to **THEJUS JOSEPH** in **Settings → General**.
5. Go to **Appearance → Customize → Homepage Content** to replace the demo portrait, signature, statistics and journey-card content.
6. Create a menu and assign it to **Primary Menu**.

## Important
WordPress.com only allows uploading custom themes on plans that support custom theme uploads. On Hostinger, AWS/Lightsail, DigitalOcean, Cloudways, or any normal self-hosted WordPress install, this theme can be uploaded directly.

## Replace the demo imagery
The included images were cropped from the reference screenshot only to make the first install visually resemble the concept. Replace them with original high-resolution images before publishing.

## Recommended image sizes
- Hero portrait: 1200 × 1500 px or larger, vertical
- Journey images: 1200 × 700 px or larger
- Signature: transparent PNG/WebP, around 600 × 250 px

## SEO / performance
- Semantic HTML and native WordPress title support
- No page-builder dependency
- Minimal JavaScript
- Responsive CSS
- Google Fonts are loaded externally; for maximum performance/privacy, self-host fonts later
